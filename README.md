# ERPIPS Demo Workspace

Folder ini berisi basis fullstack Laravel dari ERP saat ini, ditambah kebutuhan demo entitlement fitur per client.

## Isi Utama

- Source Laravel: `app/`, `config/`, `database/`, `resources/`, `routes/`, dst.
- Dokumen kebutuhan bisnis dan arsitektur demo:
  - `docs/demo-feature-entitlement-mvp.md`

## Fokus Demo

- Paket + add-on per client
- Kontrol superadmin untuk buka/tutup fitur
- Gating konsisten di UI, API, dan backend
- Pondasi modular monolith menuju microservice bertahap
